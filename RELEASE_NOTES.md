# HobbyistDecals Release Notes - Version 1.0.0

**Release Date:** December 18, 2025

This is the initial major release of HobbyistDecals, a comprehensive decal services platform. This release includes the complete foundation of the application with payment integration, admin functionality, and user-facing features.

---

## 🎉 Highlights

- **Full Production Launch**: Complete e-commerce platform for custom decals
- **Payment Gateway Integration**: Payglocal payment system with dynamic configuration
- **Admin Dashboard**: Comprehensive order and inventory management
- **Analytics Integration**: Google Analytics for user behavior tracking
- **Domain Migration**: Professional .com domain implementation
- **Security Hardening**: Enhanced security patches and protections

---

## ✨ New Features

### Payment System
- **Payglocal Integration** - Integrated Payglocal payment gateway for secure transactions ([#15](https://github.com/Anave-Decal-Services-Pvt-Ltd/hobbyistdecals/pull/15))
- **Dynamic Payment Configuration** - Made Payglocal client key dynamic for better environment management ([#18](https://github.com/Anave-Decal-Services-Pvt-Ltd/hobbyistdecals/pull/18))

### Admin Features
- **Admin Dashboard** - Comprehensive admin dashboard for order management and analytics ([#24](https://github.com/Anave-Decal-Services-Pvt-Ltd/hobbyistdecals/pull/24))
- **Rate Card Management** - Multiple rate card version updates with improved pricing structure ([#8](https://github.com/Anave-Decal-Services-Pvt-Ltd/hobbyistdecals/pull/8), [#27](https://github.com/Anave-Decal-Services-Pvt-Ltd/hobbyistdecals/pull/27))
- **Excel Upload Control** - Disabled upload excel button for better data integrity ([#30](https://github.com/Anave-Decal-Services-Pvt-Ltd/hobbyistdecals/pull/30))

### User Experience
- **Homepage Dashboard** - Updated homepage with improved dashboard and user experience ([#25](https://github.com/Anave-Decal-Services-Pvt-Ltd/hobbyistdecals/pull/25))
- **Enhanced Search** - Improved search functionality for better product discovery ([#27](https://github.com/Anave-Decal-Services-Pvt-Ltd/hobbyistdecals/pull/27))
- **Construction Mode** - Added construction popup for production environment during maintenance ([#21](https://github.com/Anave-Decal-Services-Pvt-Ltd/hobbyistdecals/pull/21), [#22](https://github.com/Anave-Decal-Services-Pvt-Ltd/hobbyistdecals/pull/22))

### Analytics & Tracking
- **Google Analytics** - Integrated Google Analytics for user behavior tracking and insights ([#32](https://github.com/Anave-Decal-Services-Pvt-Ltd/hobbyistdecals/pull/32))

### Domain & Infrastructure
- **Domain Migration** - Updated from .in to .com domain for global reach ([#32](https://github.com/Anave-Decal-Services-Pvt-Ltd/hobbyistdecals/pull/32))
- **Layout Updates** - Updated layout page for staging environment ([#35](https://github.com/Anave-Decal-Services-Pvt-Ltd/hobbyistdecals/pull/35))
